1. Executive Abstract

Wind energy is inherently non-linear, stochastic, and governed by atmospheric boundary layer dynamics. Accurate hourly wind power forecasting is essential for modern grid dispatchers, transmission system operators (TSOs), and wind farm owners to maintain grid frequency stability, optimize spinning reserves, and avoid heavy financial penalties under statutory Deviation Settlement Mechanism (DSM) regulations.

AeroCast-AI is a physics-informed, hybrid probabilistic forecasting architecture developed by team Prompt Diplomats. We fuse domain aerodynamic equations (Hellmann wind shear vertical extrapolation, non-linear $P \propto v^3$ kinetic flux mapping, and thermodynamic air density computation) with a dual-engine architecture: an ultra-fast multi-quantile gradient boosting engine (LightGBM/CatBoost) and a multi-horizon Temporal Fusion Transformer (TFT). Crucially, AeroCast-AI delivers Conformal Quantile Envelopes ($P_{10}, P_{50}, P_{90}$) with strict physical boundary guards to guarantee zero negative power predictions and zero cut-out aerodynamic violations.

import math
import numpy as np
import pandas as pd

class AeroCastPipeline:
    def __init__(self, hub_height=120.0, mast_height=10.0, rated_power=100.0):
        self.hub_height = hub_height
        self.mast_height = mast_height
        self.rated_power = rated_power
        self.v_cut_in = 3.0    # m/s
        self.v_rated = 12.5   # m/s
        self.v_cut_out = 25.0 # m/s
        self.R_specific = 287.058 # J/(kg·K)

    def extract_physics_features(self, df: pd.DataFrame) -> pd.DataFrame:
        """Applies aerodynamic laws and vector conditioning."""
        data = df.copy()

        # 1. Atmospheric Air Density (kg/m³) using Ideal Gas Law
        # p in Pa, T in Kelvin
        temp_k = data['temperature'] + 273.15
        data['air_density'] = data['pressure'] / (self.R_specific * temp_k)

        # 2. Hellmann Power Law: Vertical Wind Shear Extrapolation
        # alpha dynamically estimated or default 0.143
        alpha = data.get('wind_shear_alpha', 0.143)
        data['wind_speed_hub'] = data['wind_speed_10m'] * ((self.hub_height / self.mast_height) ** alpha)

        # 3. Trigonometric Vector Decomposition (eliminating 0° / 360° discontinuity)
        rad = np.radians(data['wind_direction'])
        data['wind_u'] = data['wind_speed_hub'] * np.cos(rad)
        data['wind_w'] = data['wind_speed_hub'] * np.sin(rad)

        # 4. Aerodynamic Kinetic Flux Index (Proportional to P ~ 0.5 * rho * v^3)
        data['kinetic_flux'] = 0.5 * data['air_density'] * (data['wind_speed_hub'] ** 3)

        # 5. Theoretical S-Curve Power Proxy
        v = data['wind_speed_hub']
        theoretical_ratio = np.clip((v - self.v_cut_in) / (self.v_rated - self.v_cut_in), 0, 1) ** 3
        data['theoretical_power'] = np.where(
            (v >= self.v_cut_in) & (v <= self.v_rated),
            theoretical_ratio * self.rated_power,
            np.where((v > self.v_rated) & (v <= self.v_cut_out), self.rated_power, 0.0)
        )

        # 6. Cyclical Temporal Encodings
        data['hour_sin'] = np.sin(2 * np.pi * data['hour'] / 24.0)
        data['hour_cos'] = np.cos(2 * np.pi * data['hour'] / 24.0)

        return data

    def enforce_physical_guards(self, preds: np.ndarray, wind_speed_hub: np.ndarray) -> np.ndarray:
        """Guarantees zero unphysical generation values."""
        # Clip strictly between 0 and Nameplate Capacity
        clipped = np.clip(preds, 0.0, self.rated_power)
        # Enforce aerodynamic shut-down above cut-out speed
        clipped = np.where(wind_speed_hub > self.v_cut_out, 0.0, clipped)
        # Enforce zero power below cut-in speed
        clipped = np.where(wind_speed_hub < self.v_cut_in, 0.0, clipped)
        return clipped
